# Sharing files with links
## Create a link
Right-click a file, choose Share, then Create link. Anyone with the link can view the file.
## Expiry and passwords
Links can expire after 1 to 90 days. The default expiry is 7 days. Password-protected links are available on Plus and Pro.
## Stop sharing
Open Shared links and click Disable next to a link. It stops working immediately.
